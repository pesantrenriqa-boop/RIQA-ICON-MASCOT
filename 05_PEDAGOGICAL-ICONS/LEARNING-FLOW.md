# Pedagogical Icon Flow

Alur utama peserta RIQA harus dapat dipahami secara visual:

**Masuk → Belajar → Latihan → Ujian → Hasil → Sertifikat / Lanjut Kompetensi**

## Ikon Utama
1. Mulai
2. Belajar
3. Dengarkan
4. Baca
5. Ucapkan
6. Rekam
7. Latihan
8. Kirim jawaban
9. Ujian
10. Hasil
11. Perbaiki
12. Lulus
13. Sertifikat
14. Kompetensi berikutnya

Tujuan sistem ini adalah mengurangi ketergantungan pada banyak tombol teks dan membuat RIQA OS lebih intuitif.
