# RIQA ICON & MASCOT

Official icon, mascot, character, and visual identity system for **RIQA — Rumah Ilmu Al-Qur'an**.

## Tujuan
Repository ini menjadi sumber tunggal identitas ikon dan maskot RIQA untuk:
- RIQA OS
- website resmi RIQA
- aplikasi peserta, wali santri, guru, admin, dan supervisor
- materi pembelajaran QURBATA
- media sosial, poster, sertifikat, dan publikasi
- merchandise dan signage

## Prinsip Identitas
Maskot dan ikon RIQA harus terasa:
1. Qurani
2. Ramah dan mudah dikenali
3. Modern, bukan kekanak-kanakan
4. Profesional untuk lembaga pendidikan
5. Konsisten di web, mobile, cetak, dan media sosial
6. Sederhana saat dipakai sebagai ikon kecil
7. Memiliki karakter khas RIQA, bukan ikon generik

## Arah Maskot
Maskot utama RIQA dikembangkan sebagai **sahabat belajar Qurani modern** yang mewakili:
- Al-Qur'an
- ilmu
- adab
- keberanian dan percaya diri
- teknologi yang bermanfaat
- suasana pesantren yang hangat

Maskot tidak menggantikan logo resmi RIQA. Logo adalah identitas institusi; maskot adalah identitas karakter dan pengalaman pengguna.
