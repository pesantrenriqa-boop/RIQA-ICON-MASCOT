# RIQA Icon Guidelines

## Style
- sederhana
- rounded
- stroke konsisten
- tidak terlalu tipis
- detail minimum
- dapat terbaca pada ukuran kecil

## Grid
Master icon disiapkan pada grid **24 × 24**.

## Variants
Setiap ikon idealnya memiliki:
- outline
- filled (hanya jika dibutuhkan untuk state aktif)

## Naming
Gunakan lowercase-kebab-case.

Contoh:
- `riqa-home.svg`
- `riqa-belajar.svg`
- `riqa-ujian.svg`
- `riqa-quran.svg`
- `riqa-bahasa-arab.svg`

## Accessibility
Ikon penting harus memiliki label teks atau accessible name pada implementasi UI.
