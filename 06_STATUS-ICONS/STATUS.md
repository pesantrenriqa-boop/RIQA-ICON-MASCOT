# Status Icons

Status harus konsisten di seluruh RIQA OS.

- Locked — belum dapat diakses
- Available — tersedia
- In Progress — sedang dipelajari
- Submitted — sudah dikirim
- Passed — lulus
- Needs Review — perlu diperiksa
- Retry — perlu mengulang
- Verified — terverifikasi
- Certificate Ready — sertifikat tersedia

Warna tidak boleh menjadi satu-satunya pembeda status; bentuk/simbol juga harus berbeda.
